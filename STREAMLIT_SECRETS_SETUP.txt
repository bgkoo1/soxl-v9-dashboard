V9 실제 보유수량 영구저장 설정

1) GitHub에서 Fine-grained personal access token 생성
   - Repository access: Only select repositories -> soxl-v9-dashboard
   - Repository permissions -> Contents: Read and write
   - 토큰 생성 후 값 복사

2) 암호화 키 생성
   로컬에서 다음 실행:
   py generate_encryption_key.py
   출력된 문자열을 복사

3) Streamlit Community Cloud -> 해당 앱 -> Settings -> Secrets에 아래 입력

GITHUB_TOKEN = "여기에_GitHub_토큰"
PORTFOLIO_ENCRYPTION_KEY = "여기에_암호화키"
GITHUB_REPO = "bgkoo1/soxl-v9-dashboard"
GITHUB_BRANCH = "main"

4) Save 후 앱 재부팅

5) 대시보드의 '실제 보유수량 수정'에서 수량 변경 후
   '수정 수량 적용·영구저장' 클릭

정상 연결 시:
   🔐 영구저장 연결됨
표시가 나타납니다.

실제 수량은 GitHub에 live_portfolio.enc 파일로 암호화되어 저장됩니다.
PORTFOLIO_ENCRYPTION_KEY는 GitHub 코드나 파일에 절대 올리지 마세요.
